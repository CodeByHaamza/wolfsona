# Cartes d'arcanes

**Ce dossier est volontairement vide dans le dépôt.**

Les visuels d'arcanes utilisés en production proviennent de *Persona* et appartiennent
à ATLUS / SEGA. Ils ne sont pas redistribués ici : le dépôt est public, les assets non.

Comment les obtenir et les déployer → [`docs/ASSETS.md`](../../docs/ASSETS.md).

Sans eux, le jeu fonctionne : l'interface retombe sur des cartes typographiques
(chiffre romain + nom de l'arcane), qui restent parfaitement jouables.
