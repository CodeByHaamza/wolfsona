# Code de conduite

## L'essentiel

Wolfsona est un jeu de mensonge. **Mentir dans la partie fait partie du jeu ; mentir sur
les gens, non.**

Cette distinction est tout ce code de conduite en une phrase. Accuser quelqu'un d'être un
loup est une tactique. S'en prendre à la personne derrière le pseudo n'en est pas une.

## Ce qu'on attend

- Attaquer le raisonnement, jamais la personne
- Accepter qu'on perde, et qu'on ait été manipulé — c'est le but du jeu
- Respecter les désaccords techniques, et les trancher avec des arguments

## Ce qui n'est pas toléré

- Harcèlement, insultes, propos discriminatoires de toute nature
- Attaques personnelles sous couvert de jeu de rôle
- Divulgation d'informations privées
- Révéler volontairement des informations de partie hors du jeu (spectateur qui parle,
  partage d'écran, canal parallèle entre joueurs d'un même camp)

Le dernier point est à la fois une tricherie et un manquement au respect des autres joueurs.
